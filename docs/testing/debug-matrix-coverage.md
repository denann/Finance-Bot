## Classification rules

- `AUTOMATED_OFFLINE`: a deterministic assertion executes the relevant parser, route registry, safety boundary, split allocation, or immutable action contract.
- `AUTOMATED_WITH_FAKE_STATE`: an assertion uses in-memory state and proves no production mutation.
- `LIVE_AI_EVAL`: quality depends on Gemini and is excluded from default pytest.
- `STAGING_REQUIRED`: the remaining claim depends on real Telegram ordering, image delivery, gspread semantics, scheduler timing, or a full handler interaction.
- `AMBIGUOUS_EXPECTATION`: current behavior and matrix intent differ and need an owner decision.
- `OBSOLETE_EXPECTATION`: Phase 0 intentionally replaced an older direct-write expectation with final confirmation.
