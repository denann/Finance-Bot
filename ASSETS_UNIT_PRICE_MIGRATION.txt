# Assets Unit Price Migration

Tambahkan kolom berikut di tab `assets` kalau belum ada:

asset_type
quantity
unit
price_source
price_per_unit
last_price_update

Header final yang direkomendasikan:

id | name | category | current_value | description | is_active | created_at | updated_at | asset_type | quantity | unit | price_source | price_per_unit | last_price_update

Flow baru:

1. Tambah aset satuan natural:
   add emas 41 gram
   add laptop 1 buah

2. Bot akan bertanya harga satuan:
   Harga 1 gram berapa?
   Harga 1 buah berapa?

3. Balas harga satuan:
   2410000
   2.41 juta
   8000000

4. Bot menyimpan:
   current_value = quantity × price_per_unit

5. Edit harga satuan:
   /asset_update asset_xxx | unit_price=2420000
   /asset_update asset_xxx | harga_satuan=2.42 juta

Catatan:
- Auto fetch Antam dinonaktifkan agar tidak kena 403.
- price_source disimpan sebagai manual.
